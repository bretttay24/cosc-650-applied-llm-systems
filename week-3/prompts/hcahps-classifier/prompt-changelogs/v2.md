## v2 (09-12-2026)

**Changed:** Added targeted edge-case rules to the V1 prompt. The rules distinguish medication communication during a hospital stay from medication management after discharge and clarify when discharge-planning concerns belong to `care_transition`.

**Reason:** Evaluation of V1 identified label-classification errors in ambiguous cases that could reasonably fit more than one category. I added rules for those cases without changing the core label definitions or test criteria.

**Impact:** Label accuracy improved from 90% to 100%. Rationale semantic similarity was essentially unchanged, decreasing slightly from 0.670 to 0.667. Input token usage increased by fewer than 100 tokens. Confidence calibration did not improve; the model continued to predict `high` confidence for every case.

**Eval:** Compared V1 and V2 on the same 20-case test suite using exact-match label and confidence accuracy, rationale semantic similarity, and token usage.
